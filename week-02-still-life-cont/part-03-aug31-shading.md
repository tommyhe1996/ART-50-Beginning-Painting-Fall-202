# Shading Still Life

## Value

**Value = light and dark.**

In representational painting, value helps create the appearance of:

- volume
- form
- space
- distance

Gradations from light to dark can make a flat painted object appear three-dimensional.

The use of value in representational art is commonly called **shading**. :contentReference[oaicite:1]{index=1}

---

# Value and Depth

Value contrast can also create a sense of distance.

- Higher value contrast can make an area appear closer.
- Lower contrast can make an area appear farther away.
- Distant objects may become less distinct as they recede into space. :contentReference[oaicite:2]{index=2}

# 2. Shade on the Object

Shade is the darker area that appears on the object itself where less light reaches the surface.

For the ping-pong balls, shading should help make each circle appear like a three-dimensional sphere.

Instead of painting one flat color, I need to create a gradual change between:

- lighter value
- middle value
- darker value

---

# 3. Shadow

A shadow is created when the object blocks light from reaching another surface.

The shadow should relate to the direction of the light source.

The lecture emphasizes that shadows need **different tones**, rather than one flat dark tone.

According to the example on page 3:

- Objects without shadows do not look realistic.
- Objects with one even shadow tone still do not look fully realistic.
- Shadows with varied tones look more realistic because some areas receive less light than others. :contentReference[oaicite:4]{index=4}

---

# 4. Lightest Area

I need to determine:

**Where is the strongest light hitting my composition?**

This area should contain one of the lightest values in the painting.

The lightest area should connect logically to the light source.

---

# 5. Darkest Area

I also need to decide:

**Where is the least amount of light reaching the composition?**

This will create one of the darkest values.

The darkest value might appear:

- on the shaded side of an object
- underneath an object
- where two objects overlap
- in part of a cast shadow
